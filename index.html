接続できないときに見るところ
  1. URL の種類：AKfycb… だけの文字列は「デプロイID」です。使うのは https://script.google.com/macros/s/AKfycb…/exec という形のウェブアプリURLです。
  2. URL の末尾：?token=… が付いていたら消してください（この画面では自動で消します）。/dev ではなく /exec です。
  3. デプロイのし直し：Apps Script のコードを直しただけでは反映されません。［デプロイを管理］→ 鉛筆マーク →［バージョン］を「新しいバージョン」にして［デプロイ］を押してください。
  4. アクセスできるユーザー：「全員」にしてください。「Googleアカウントを持つ全員」だと、このアプリからは弾かれます。
  5. 合言葉：Apps Script の ACCESS_TOKEN と、この画面の合言葉が同じ文字列である必要があります。
