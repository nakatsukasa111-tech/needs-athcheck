# ボディマップ 部位の対応表（叩き台）

人体図に色を塗るために、「どの種目が、どの部位に効くと見なすか」を決めた表です。
**この表は測定結果ではなく、私（Claude）が作った解釈の案です。** トレーナーの判断で直してください。

作成：2026-09-23 ／ 状態：**未確定・レビュー待ち**
試作画面： https://nakatsukasa111-tech.github.io/needs-athcheck/prototype/bodymap.html

## 大前提（ここが一番大事です）

私たちが測っているのは **「動作」であって「部位」ではありません。**

たとえばバンザイが1点だったとき、原因が肩関節なのか、胸椎なのか、広背筋なのかは**測定からは分かりません**。
それを「肩が赤」と塗るのは、測定結果ではなく**解釈を一枚かぶせている**ということです。

そのため、

- この表は**必ず公開・明示**し、「そう決めたから、そう塗っている」と言える状態にする
- アプリ上でも、部位をタップすれば**根拠になった種目と点数が見える**ようにする
- トレーナーが実際に触って得た所見と食い違ったときは、**所見のほうが正しい**という前提で使う

この3つを守らないと、図のほうが独り歩きします。

## 重みの意味

| 記号 | 重み | 意味 |
|---|---|---|
| ◎ | 1.0 | 主にこの部位を見ている |
| ○ | 0.5 | 関与する |
| △ | 0.25 | 少し関与する |

**部位の点数 ＝ その部位に集まった種目の「重み付き平均」** です。
例：肩（左）に バンザイ1点(◎)・結帯0点(◎)・肩外旋1点(◎)・ブリッジ2点(△) が集まった場合
→ (1×1 + 0×1 + 1×1 + 2×0.25) ÷ (1+1+1+0.25) = 0.77点 → 得点率 25.6% → 赤

## 決まっていること・いないこと

**決めたこと（暫定）**

- 硬さと強さは1枚に混ぜられないので、**3つの見方を切り替える**（柔軟性／筋力／バランス・連動）
- 左右がある種目は、左右それぞれの部位に振り分ける
- 左右がある種目が**中央の部位**（背中・腰・腹部など）に入る場合は、**低いほうの点数**を採用する
  （本番アプリの柔軟性の扱いと同じ考え方）
- 測定していない部位は**グレー**。緑にはしない
- 正面・背面の2枚のみ。側面は姿勢評価を項目に加えたときに検討
