# 人体図（ボディマップ）の作り方

試作 `prototype/style-sample.html` が使っている人体図は、
**中務さんが作成したイラストをそのまま使っています。** 輪郭をコード側で描いてはいません。

最終更新：2026-09-24

---

## 元になっている絵

`prototype/assets/人体図_原画.png`

1枚のPNGに、3つのパネル（男性・女性・中性）が縦の罫線で区切られ、
各パネルに前面・後面の2体、合わせて6体が描かれています。
上下に色つきの見出し帯と脚注があります。

**絵を差し替えるときは、この構成を保ってください。** 構成が変わる場合は
取り込みスクリプトの `PANEL_LINES` と `Y0 / Y1` を測り直す必要があります。

---

## 取り込み方

```
pip install pillow numpy
python3 tools/人体図を取り込む.py > /tmp/figs.js
```

出力された `var FIGS = {...};` を、`prototype/style-sample.html` の同じ部分と入れ替えます。
スクリプトは1枚のPNGから、6体それぞれについて次の3つを作ります。

### 1. 線画（`img`）

白地を落として「白＝線」の濃淡画像にし、**16階調**に落としてPNGにして base64 で埋め込みます。
SVGの `<mask>` として使い、その上から濃紺の矩形を塗ることで線画として見えます。

16階調にしているのは容量のためです。1体あたり67KB → **14KB**（6体で約85KB）。
背景のごくうすい濃淡（値16未満）も捨てています。これをしないと容量が4倍になります。

### 2. 切り抜き（`d`）

線の内側を塗りつぶして輪郭をトレースした `<path>` です。
色の「にじみ」をこのパスで切り抜くので、色が体の外にはみ出しません。

作り方は、**外周から白い部分を塗りつぶして、残った部分＝体の中**とする方法です。
線に1画素でも隙間があると外に漏れるため、線を1画素太らせてから塗っています。

### 3. 色を置く位置（`shY` ほか）

6枚それぞれから、**確実に測れる場所だけ**を実測しています。

| 値 | 中身 | 測り方 |
|---|---|---|
| `shY` / `shHalf` | 肩の高さと肩幅の半分 | 上半身でいちばん幅が広い行 |
| `crotchY` | 股の高さ | 正中線に体がなくなる最初の行 |
| `thigh` / `knee` / `calf` | 太もも・膝・ふくらはぎ | 脚が2本に分かれてからの、幅の最小・最大 |
| `armOuter` | 腕の外側 | 胴の高さで、いちばん外にある部分 |
| `axisOff` | 絵の中心と体の正中線のずれ | ウエストあたりの体の中心 |

胸・腹・体側・骨盤・臀部などは、この実測値からの**相対**で置いています
（`blobSpots()` を参照）。だから体格の違う3体でも、同じ部位が同じところに出ます。

## つまずいた点（同じことを繰り返さないために）

- **正中線は絵の中心ではありません。** 最大4ポイントずれています（`axisOff`）。
  これを足さないと、左右対称に置いたはずの色が片側に寄ります
- **隣り合う2体は手が触れています。** そのままだと1つの図形として繋がるので、
  いちばん細いところで切り分けています
- **パネルの縦罫線も「線の内側」として拾われます。** 罫線の列を除外しないと、
  罫線と図がひとつながりになります
- **腕が胴に接している図があります**（女性・中性の一部）。
  そのため「脇の下」「ウエストの幅」は自動では測れません。肩幅からの割合で置いています
- **◎と！の印は、細い部位では自動的に小さくなります**（にじみの横幅の0.62倍が上限）。
  上腕やふくらはぎで輪郭からはみ出さないようにするためです

## 変更したときの確認

ブラウザ（Chromium + Playwright）で、3タブ × 4サンプル × 3体型の36通りを開き、
**印が輪郭からはみ出していないか**を `isPointInFill` で機械的に確かめています。
印の位置や大きさを変えたときは、この確認をやり直してください。
