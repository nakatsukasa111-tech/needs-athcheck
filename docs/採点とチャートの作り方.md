# NeeDS フィジカルチェック — 点数とチャートの作り方

このアプリが、測定値をどう点数に変え、どうチャートにしているかをまとめたものです。
トレーナー間で見方をそろえるため、また基準を見直すときの土台として使ってください。

最終更新：2026-09-24

---

## 1. 大きな流れ

```
測定値を入力
  ↓  ① 1種目ごとに 1〜3点（柔軟性と動きの質は 0〜3点）をつける
点数
  ↓  ② 部門ごとに「得点率（100点満点）」にする
部門の点数
  ↓  ③ 5部門の平均が総合スコア
総合スコア
```

**測っていない項目は、分母から外れます。** 0点にはなりません。
体験時に数項目しか測らなくても、測った項目だけで正しく評価されます。

---

## 2. 1種目に点数をつける — 3つのやり方

### やり方A：そのまま0〜3点で入力する（柔軟性15項目・動きの質5項目）

トレーナーが目で見て0〜3点をつけます。

**0点は「怪我などで測定不能」「痛みはないが病的な硬さがある」ときに使います。**
0点は「測っていない」とは違い、0点として集計に入ります。

**左右がある種目は、低いほうの点数を種目の点数にします。**
柔軟性は制限がある側が問題になるため、平均ではなく低い側を採ります。
これで各部位が3種目・9点満点にそろいます。

### やり方B：実測値を閾値で1〜3点に変換する（バランス・筋力・ジャンプ）

`thresholds` シートの `red_max` と `green_min` を見て判定します。

| 実測値 | 点数 | 色 |
|---|---|---|
| `red_max` 以下 | 1点 | 赤（要改善） |
| `red_max` より上、`green_min` 未満 | 2点 | 黄（普通） |
| `green_min` 以上 | 3点 | 緑（良好） |

閾値は **性別（男/女）× 年齢区分（17歳以上／16歳以下）** ごとに別々の行を持っています。
その選手に合う行が自動で選ばれます。

### やり方C：体重比で判定する（ベンチプレス・スクワット・デッドリフトの1RM）

保存するのは実測kgですが、**採点は「1RM ÷ 体重」の体重比**で行います。
表示は「115 kg（体重比 1.64）」のように併記します。

**体重が未入力だと1RM系は採点できません**（「体重未入力のため採点対象外」と出て分母から外れます）。
測定画面で先に体重を入れてください。

聞き取りや推定で入れた値は「推定」にチェックを入れると、推移グラフで点線と白い点に区別されます。

## 3. 部門の点数（得点率）と色

```
得点率 ＝ 入力済み項目の合計点 ÷（入力済み項目数 × 3）× 100
```

| 得点率 | 判定 | 色 |
|---|---|---|
| 88.9% 以上 | 良好 | 緑 #3B8F68 |
| 66.7% 以上 | 普通 | 黄 #D89A1F |
| 66.7% 未満 | 要改善 | 赤 #C7453F |

これは「3種目9点満点で 8〜9点＝緑、6〜7点＝黄、0〜5点＝赤」という比率を一般化したものです。
柔軟性の部位別にも、動きの質にも、同じ比率を使います。

**総合スコア**は、5部門（柔軟性・バランス・筋力・ジャンプ・動きの質）の得点率の平均です。
いまは5部門とも同じ重みですが、重みは後から変えられるようにしてあります。

筋力は体幹部・上半身・下半身の、柔軟性は上半身・体幹部・下半身の小計も出しています。

## 4. 部門ごとのレーダーチャート

部門カードの左がレーダー、右が種目別の棒グラフです。
**レーダーはどの軸も「外側ほど良い」**で統一しています（0〜100）。

### 柔軟性・筋力（同じ考え方）

| 軸 | 中身 |
|---|---|
| 上半身 | 上半身3種目の得点率 |
| **上半身と体幹部のつながり** | 下の式 |
| 体幹部 | 体幹部3種目の得点率 |
| **下半身と体幹部のつながり** | 下の式 |
| 下半身 | 下半身3種目の得点率 |

軸は、つながりの軸がそれをつなぐ2つの部位のちょうど間に来るよう、交互に並べています。
形を見ただけで「上半身は出ているのに体幹が凹んでいる＝間のつながりも凹む」と読めます。

**つながりの計算**

```
つながり ＝「100 − 2部位の差」と「2部位の平均」の、低いほう
```

意味は2つです。**部位の差が大きいと下がる**（つながっていない）、
**両方とも低ければそれ以上には上がらない**（差がなくても、どちらも硬ければつながりは良くない）。

| 上半身 | 体幹部 | つながり | 読み方 |
|---|---|---|---|
| 100 | 33 | **33** | 上半身は柔らかいが体幹が硬い。間で力が切れている |
| 90 | 50 | **60** | やや差がある |
| 33 | 33 | **33** | 差はないが、両方硬いのでつながりも良くない |
| 90 | 90 | **90** | どちらも良く、差もない |

### バランス

片脚立位を**静的バランス**、地面タッチを**動的バランス**として扱います。

| 軸 | 中身 |
|---|---|
| 静的バランス | 片脚立位の左右の平均点 |
| 静的の左右差 | 片脚立位の左右の点数差 |
| 静的と動的の差 | 静的と動的の平均点の差 |
| 動的の左右差 | 地面タッチの左右の点数差 |
| 動的バランス | 地面タッチの左右の平均点 |

**差の軸は、レーダーの向き（外側＝良い）に合わせて反転させています。**

| 点数の差 | レーダー上の値 | 色 |
|---|---|---|
| 0 | 100 | 緑 |
| 1 | 66.7 | 黄 |
| 2以上 | 33.3 | 赤 |

差が小さいほど外側に出ます。「静的と動的の差」は平均点どうしの差なので 0.5 のような端数が出ますが、
その場合は間の値として連続的に扱います。

### ジャンプ

| 軸 | 中身 |
|---|---|
| 跳躍高 | SQJ・CMJ・ABJ の点数の平均 |
| 反動の使い方 | SQJ→CMJ の伸び率の判定 |
| 腕振りの連動 | CMJ→ABJ の伸び率の判定 |
| 片脚 | SLCMJ 左右の点数の平均 |
| RSI | ホップテスト・ドロップジャンプの点数の平均 |

## 5. ジャンプの中身をどう読むか

各ジャンプが何を表しているか。

- **SQJ（反動なし）**：筋力そのものの強さ
- **CMJ（反動あり・腕振りなし）**：下半身の反動・伸張反射（SSC）の活用度
- **ABJ（腕振りあり）**：腕振り・上半身からの連動性

### 反動の使い方（SQJ → CMJ の伸び率・標準は10%前後）

| 伸び率 | 判定 |
|---|---|
| 3%未満 | 反動をほとんど使えていない。伸張反射が機能しておらず、筋力をそのまま跳躍に変換している |
| 3〜15% | 標準的 |
| 15%超 | 反動の使い方は上手いが、筋力そのものが不足。SQJを上げればCMJも連動して伸びる |

### 腕振りの連動（CMJ → ABJ の伸び率）

| 伸び率 | 判定 |
|---|---|
| 5%未満 | 腕振りと上半身の連動が機能していない。上半身の力を下半身に伝えられていない |
| 5〜11% | 標準的 |
| 11%超 | 連動は良好。同時にCMJ側にまだ伸びしろがある |

ABJは腕振りがある分CMJより高いのが正常です。
**「連動不足」は伸び率が足りないという意味で、「ABJが低い」ではありません。**

### 片脚（SLCMJ）— 2つの見方を両方する

1. **相対**：両脚CMJの50%が目標値。目標の±5%以内なら達成、90%未満で赤
   （例：CMJ 40cm → 目標20cm、19〜21cmが許容）
2. **絶対値**：`thresholds` の `sl_cmj` の行で判定

相対だけだと「両脚とも弱いがバランスは良い」選手を見逃すため、両方見ます。

### 「ジャンプの質」の棒グラフ

上の解説と同じ内容を、棒の長さ＝判定、先の数字＝実測値で並べたものです。
反動の使い方／腕振りの連動／片脚の目標比 左右／ホップとドロップのRSI差。

## 5-2. ボディマップ「体のどこに出ているか」

結果画面に、人体図（前面・背面）を出しています。**総合スコアには影響しません。**
測った種目から「どの部位に出ているか」を色で示すだけの、読み取りの補助です。

### 見方

| 色 | 意味 |
|---|---|
| 緑・黄・赤 | 部位の得点率。境目は部門カードと同じ（88.9 / 66.7） |
| ◎ | 満点の部位 |
| 赤の！ | 33.3%以下の部位 |
| 色なし（グレー） | その部位を見る種目を測っていない |

上のタブで **柔軟性／筋力／バランス・連動** を切り替えます。
硬さと強さは1枚に混ぜられないため、見方を分けています。
測っていない見方のタブは押せません。

体型は**会員登録の性別**で男性・女性・中性を自動で切り替えます。

### 部位の点数の出し方

```
部位の点数 ＝ その部位に集まった種目の「重み付き平均」
重み  ◎ 1.0（主に見ている）／ ○ 0.5（関与する）／ △ 0.25（少し関与する）
```

- 左右がある種目は、左右それぞれの側の部位へ振り分けます
- 左右がある種目が**中央の部位**（胸・背中・腹部・腰）に入るときは、**低いほうの点数**を採ります
- 測っていない種目は分母から外れます。部位に1種目も集まらなければグレーのまま

### 大前提

**私たちが測っているのは「動作」であって「部位」ではありません。**
バンザイが1点だったとき、原因が肩関節なのか胸椎なのか広背筋なのかは測定からは分かりません。
それを「肩が赤」と塗るのは、測定結果ではなく**解釈を一枚かぶせている**ということです。

そのため、

- **部位をタップすると、根拠になった種目と点数、その重みが出ます。** 必ずここを見せられる状態にしてあります
- 対応表は `docs/部位の対応表_叩き台.md` に公開しています（**まだ暫定です**）
- トレーナーが実際に触って得た所見と食い違ったときは、**所見のほうが正しい**という前提で使ってください

## 6. 左右差とフラグ（総合スコアには足さない）

左右差は点数に加算せず、**「気をつけたい点」に独立して出します。**

| 対象 | 基準 |
|---|---|
| 柔軟性（0〜3点の種目） | 1点差 → 黄「左右差があります」／2点以上 → 赤「左右差が大きい」 |
| SLCMJ・SLスクワット・片脚立位・地面タッチ | 高いほうを100とした差が **10%以上で赤**。絶対値が高くても改善が必要と判定 |
| ホップ／ドロップのRSI | 差が **15%以上でフラグ** |
| RSI | どちらかが **3.1以上**なら「非常に良い」と表示（色は緑のまま） |

## 7. 基準を変えたいとき

スプレッドシートの `thresholds` と `rules` を書き換えて保存し、アプリを再読み込みするだけです。
**プログラムの修正は要りません。**

- `thresholds`：項目ごと・男女別・年齢区分別の `red_max` / `green_min`
- `rules`：色の境界、左右差フラグ、ジャンプの伸び率の基準、ジュニア／大人の境界（17歳）など

書き換えていいのは `red_max` / `green_min` / `value` / `note` だけです。
`item_key` / `sex` / `age_band` / `rule_key` と列名は変えないでください（アプリが項目を見つけられなくなります）。

**過去の測定も、いまの基準で計算し直して表示されます。**
実測値がそのまま残っているので、基準を調整しても推移グラフが壊れません。

## 8. いまの基準の信頼度

| 出どころ | 項目 |
|---|---|
| **確定**（中務さんの指定値） | 成人男性の ABJ・CMJ・SQJ・RSI・ベンチプレス |
| **係数で算出** | 女性・ジュニア（跳躍高 女性=男性×0.78、RSI ×0.80、1RM上半身 ×0.65 など。根拠は閾値マスタのREADMEシート） |
| **仮置き** | 上記以外 |
| **要確認（最も不確か）** | **片脚立位と地面タッチ**。NeeDS独自プロトコルで参照できる文献がない。PLベーシックも同様 |

片脚立位と地面タッチは、**実測データが20〜30件たまった時点で、その分布から引き直す前提**です。
それまでは、この2項目の色は参考程度に見てください。
